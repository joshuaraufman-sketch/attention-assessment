# Clinical Attention Assessment

A draft clinical attention assessment tool, bundling a primary intake form with five standalone administration aids (Digit Span, CPT, Finger Counting, Months Backward, Serial Subtraction).

**This is a draft instrument. It has not been validated for clinical use.**

## Static site — no build step

The site is plain HTML with React loaded via Babel-in-browser. There is no bundler, no `npm install`, and no build pipeline.

## Viewing locally

Either:

- Open `index.html` directly in a browser, or
- Serve the directory:

  ```sh
  python3 -m http.server
  ```

  then visit <http://localhost:8000>.
